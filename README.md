# Wilco Host releases

Wilco Host connects the Wilco app on iPhone and iPad to Pi, the coding agent on your Mac.
This repository holds its signed and notarized releases for macOS 26 or later, and the
update feed (`appcast.xml`) the app checks.

- Download the latest DMG from [Releases](https://github.com/MatrixReligio/wilco-releases/releases/latest), or
- install it with Homebrew: `brew install --cask matrixreligio/tap/wilco-host`

Wilco for iPhone and iPad: [App Store](https://apps.apple.com/app/id6839542781) ·
[matrixreligio.com](https://matrixreligio.com/en/products/wilco/)
